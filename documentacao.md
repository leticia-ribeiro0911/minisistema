# Gestão de alunos.
## Mini sistema com crud HTML + CSS + PHP + postgres.

### Objetivos:
1. Relatório de alunos cadastrados.
O relatório de alunos cadastrados é a parte do sistema que mostra a lista de alunos cadastrados no banco de dados. 

O arquivo utilizado é o `select.php`, que fica dentro da pasta `minisistema`, nele estão todos os arquivos necessários para a conexão com o banco de dados e para o cabeçalho e o rodapé da página.

2. Consulta de aluno específico.

3. Cadastrar novo aluno.

4. Excluir alunos.

5. Atualizar cadastro aluno.
